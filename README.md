# Santa — Portfolio

A responsive English-language personal portfolio for Santa, a web developer and Discord bot builder. Built as a lightweight static page with no build step.

## Preview locally

Open `index.html` in a browser. The cinematic hero uses floating code sculptures, an animated IDE window, a Discord bot badge, neon scan lines, and a glassy 3D code cube. The scene responds to pointer movement and page scrolling; sections and cards reveal as you scroll. Layout adjusts for mobile and desktop, with reduced-motion preferences respected.

## Personalize before publishing

- Replace `hello@example.com` in `index.html` with your real contact email.
- Replace the sample project concepts with your actual work, screenshots, and repository links when ready. The current cards are explicitly labeled as illustrative examples.
- Add your GitHub and Discord profile links to the footer or contact section.
- Use santa-logo.svg as the full horizontal logo and santa-mark.svg as the standalone icon and favicon.

## Publish with GitHub Pages

1. Create a new **public** repository named `YOUR-USERNAME.github.io` for a profile site, or a repository with any name for a project site.
2. Upload `index.html` and this README to the repository's root (or push them with Git).
3. For a project repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub Pages will show the published URL on that same settings page. A profile repository is served at `https://YOUR-USERNAME.github.io/`; a project repository is served at `https://YOUR-USERNAME.github.io/REPOSITORY/`.

No backend or build process is required.
